# CloudCart
## Project Summary

CloudCart is a 3-tier e-commerce application that I used to implement and demonstrate an end-to-end DevOps lifecycle. The project focuses on automating application build, security scanning, containerization, deployment, and monitoring using industry-relevant DevOps tools and AWS services.

## What I Implemented

- Created and managed the project source code using Git and GitHub.
- Configured AWS infrastructure including VPC, subnets, route tables, Internet Gateway, security groups, and EC2.
- Containerized the frontend and backend applications using Docker.
- Created a Jenkins CI/CD pipeline to automate the application delivery process.
- Integrated SonarQube for code quality analysis.
- Integrated Trivy for container image vulnerability scanning.
- Built and pushed Docker images to Docker Hub.
- Deployed the application on Kubernetes using Deployments and Services.
- Configured Kubernetes networking and application access using Ingress.
- Implemented rolling deployment and Kubernetes self-healing capabilities.
- Configured Prometheus for application and infrastructure metrics collection.
- Created Grafana dashboards for monitoring and visualization.
- Used Terraform for infrastructure provisioning and management.

## DevOps Workflow

GitHub → Jenkins → SonarQube → Docker Build → Trivy Scan → Docker Hub → Kubernetes Deployment → Prometheus → Grafana

## Key Technologies

AWS | Linux | Git | GitHub | Jenkins | Docker | Kubernetes | Terraform | SonarQube | Trivy | Prometheus | Grafana# CloudCart – End-to-End DevOps Project
